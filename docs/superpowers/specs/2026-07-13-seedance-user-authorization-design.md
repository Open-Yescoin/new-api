# Seedance 真人授权与素材库用户流程设计

日期：2026-07-13
状态：交互方案已确认，等待书面规范复核

## 背景

生产环境已经提供 BytePlus Seedance 真人素材库的服务端配置、H5 活体核验接口、`LivenessFace` 用户素材组绑定、素材 CRUD，以及 `asset://<asset_id>` 视频生成能力。现有 `/doubao/open/*` 路由使用 new-api API Token 鉴权，适合程序化调用，但普通控制台用户没有可操作页面，也无法在桌面无摄像头时把核验流程安全地交给手机完成。

本功能新增一个面向已登录用户的“真人素材库”页面。这里的“真人授权”指本人活体核验、肖像授权和同一真人素材一致性校验，不是识别陌生人的通用人脸识别功能，也不提供绕过 BytePlus H5 核验的路径。

Seedance 视频定价修正是独立工作流，不与本功能的授权数据、页面发布或数据库迁移耦合。

## 目标

- 让桌面用户通过二维码在有摄像头的手机上完成 BytePlus H5 活体核验。
- 让手机用户从控制台直接进入 H5 核验，并在回调后返回素材库页面。
- 将核验得到的 `LivenessFace GroupId` 只绑定到发起授权的当前 new-api 用户。
- 为已授权用户提供素材列表、URL 登记、状态查询、重命名、删除和 `asset://` 引用复制。
- 保持 BytePlus AK/SK、`GroupId` 和其他用户素材信息仅在服务端可见。
- 为过期、待核验、失败、配置缺失和素材处理失败提供明确、可恢复的界面状态。
- 通过 SQLite、MySQL 和 PostgreSQL 兼容的 GORM 数据模型实现会话归属校验。

## 非目标

- 不上传本地文件或建设新的对象存储；`CreateAsset` 仍只接受公网 HTTP(S) 图片或视频 URL。
- 不支持一个 new-api 用户同时绑定多位真人。
- 不把 `GroupId`、BytePlus AK/SK 或 H5 短期令牌暴露到公开 URL、日志或素材列表。
- 不自动替用户勾选条款，不模拟摄像头，不跳过本人活体核验。
- 不在本期修改 Seedance 视频售价、预扣公式或渠道配置。

## 方案选择

### 采用：控制台专用 API 与独立素材库页面

新增受 `UserAuth` 保护的控制台 API。页面使用当前登录会话，不要求用户选择或粘贴一个 new-api API Token。控制台 API 和现有 `/doubao/open/*` Token API 复用同一个 `AssetService`，避免两套授权与归属逻辑。

优点是身份来源明确、状态语义清晰、普通用户可直接使用，并能对 H5 短期令牌做服务端归属校验。代价是增加一组薄控制器和一个授权会话表。

### 未采用：通过 `ListAssets` 的 200/409 推断授权状态

该方案改动较少，但每次打开页面都必须访问 BytePlus；配置错误、上游故障和未授权都会混进素材列表错误，无法可靠展示“待核验”和“链接过期”状态。

### 未采用：只保留 API 文档

该方案无法解决 API 调用不能主动弹窗、桌面无摄像头和跨设备接力问题，因此不满足用户目标。

## 系统结构

### 1. 控制台页面

- 私有路由：`/console/seedance-assets`，由 `PrivateRoute` 保护。
- 侧边栏名称：`真人素材库`，位于工作台区域。
- 页面按授权状态显示授权卡片或素材管理区。
- 公共回调路由：`/seedance/authorization/callback`。该页面不要求登录，只显示“授权步骤已完成，请返回原设备”以及返回控制台的链接。
- 页面使用现有 `qrcode.react` 生成二维码，不引入新的二维码依赖。

### 2. 控制台 API

新增 `/api/seedance/assets` 路由组，使用 `UserAuth`：

| 方法与路径 | 作用 |
| --- | --- |
| `GET /api/seedance/assets/authorization` | 返回是否已配置、是否已授权、是否有待处理会话和绑定更新时间；不返回 `GroupId` |
| `POST /api/seedance/assets/authorization/session` | 使用服务端固定回调地址创建 H5 会话，登记当前用户的短期会话摘要 |
| `POST /api/seedance/assets/authorization/result` | 校验短期令牌属于当前用户后查询核验结果并保存 `GroupId` |
| `GET /api/seedance/assets` | 列出当前用户绑定组中的素材 |
| `POST /api/seedance/assets` | 使用公网 URL 登记图片或视频素材 |
| `GET /api/seedance/assets/:id` | 查询当前用户素材及处理状态 |
| `PATCH /api/seedance/assets/:id` | 更新当前用户素材名称 |
| `DELETE /api/seedance/assets/:id` | 删除当前用户素材 |

现有 `/doubao/open/*` 路由保持兼容，继续供 API Token 客户端使用。两套路由都必须经过同一个素材归属校验服务。

### 3. 待授权会话

新增 `VolcAssetAuthorizationSession` GORM 模型，至少包含：

- `UserId`：发起授权的 new-api 用户。
- `TokenHash`：`BytedToken` 的 SHA-256 摘要；数据库不保存原始令牌。
- `Status`：`Pending`、`Completed`、`Expired` 或 `Failed`。
- `ExpiresAt`、`CreatedAt`、`UpdatedAt`。本期本地有效期固定为 5 分钟；上游若更早返回过期，以更早者为准。

创建新会话时，使该用户之前仍处于 `Pending` 的会话失效。查询结果时，客户端提交原始 `BytedToken`，服务端计算摘要并要求它匹配当前用户尚未过期的会话。这样可以阻止另一名已登录用户拿到令牌后把别人的真人素材组绑定到自己账号。

迁移仅使用 GORM 和通用字段类型，必须同时通过 SQLite、MySQL 5.7.8+ 和 PostgreSQL 9.6+。

### 4. 回调地址

在 Seedance 素材库管理员设置中新增专用的 `AuthorizationCallbackBaseURL`。控制台会话的 `CallbackURL` 由服务端构造为：

```text
<AuthorizationCallbackBaseURL>/seedance/authorization/callback
```

控制台请求不能覆盖该地址，避免开放重定向。该配置必须是没有路径、查询参数或片段的 HTTPS origin；生产环境配置为正式用户前端域名，而不是 API 域名。若配置为空或不合法，接口返回配置错误。现有开发者 Token API 仍按其既有契约接收显式 `CallbackURL`。

## 授权数据流

1. 页面调用授权状态接口。
2. 未授权用户阅读说明并主动勾选“我确认由本人完成活体核验并授权处理真人素材”。
3. 用户点击“开始授权”，服务端创建 BytePlus H5 会话，保存令牌摘要，并将原始 `BytedToken` 与 `H5Link` 返回给当前浏览器。
4. 浏览器仅把原始 `BytedToken` 放入 `sessionStorage`。令牌不进入 URL、持久化数据库、分析事件或日志。
5. 桌面端显示 `H5Link` 二维码及“在本机打开/复制链接”；移动端主按钮在当前标签页打开 H5。
6. 发起授权的控制台页面每 3 秒调用结果接口。待处理状态不弹重复错误提示；轮询在成功、明确失败、过期或 5 分钟上限时停止。
7. BytePlus 成功返回 `GroupId` 后，服务端在同一业务操作中保存 `VolcAssetUserGroup`、把待授权会话标记为 `Completed`，并只向客户端返回 `authorized: true`。
8. 桌面二维码场景中，手机回调页只提示返回原设备；桌面页面继续轮询并自动进入素材区。
9. 手机同标签页场景中，回调页提供“返回真人素材库”按钮；返回后页面从 `sessionStorage` 恢复轮询。

若用户所有可用设备都没有摄像头，流程必须明确说明无法完成核验，而不能提供规避入口。

## 页面状态

授权区使用有限状态机，避免多个布尔值产生矛盾界面：

- `checking`：读取本地授权状态。
- `unconfigured`：管理员尚未配置素材库或公开回调地址。
- `unauthorized`：展示说明、授权条款复选框和开始按钮。
- `creating`：创建 H5 会话。
- `waiting`：显示二维码、剩余有效时间和手机操作说明。
- `authorized`：隐藏核验入口，显示素材管理区和重新授权入口。
- `expired`：提示链接过期并提供“一键重新生成”。
- `failed`：显示安全处理过的上游错误和重试按钮。

重新授权会替换当前用户的 `GroupId` 绑定。界面必须警告：原素材组中的素材不会自动迁移到新的真人组。

## 素材管理

- 列表展示名称、类型、创建时间、状态和安全处理后的失败原因。
- `Active` 素材提供“复制 `asset://...`”操作。
- `Processing` 素材可以手动刷新，并在页面可见时进行有上限的低频轮询。
- `Failed` 素材不提供 `asset://` 复制，提示用户检查是否同一真人、是否多人脸、清晰度和公网可访问性。
- 新增素材表单只接受绝对 HTTP(S) URL，类型只能是 `Image` 或 `Video`。
- 更新和删除前后端都执行当前用户素材组归属校验；跨用户素材统一返回 404。
- 删除属于不可逆的上游操作，界面必须要求二次确认。

## 安全与合规

- 授权必须由真人本人主动开始并完成，页面不得称其为可跳过的“人脸登录”。
- 页面说明处理目的：核验本人、建立真人私有素材组、检查后续素材与本人一致，并用于用户主动发起的 Seedance 视频生成。
- BytePlus AK/SK 永远只在服务端签名客户端中使用。
- 新增的控制台 API 不返回 `GroupId`；为保持兼容，现有开发者 Token API 的既有响应契约不变。日志不记录 `BytedToken`、`H5Link` 完整查询参数或人脸素材 URL。
- 待授权会话使用令牌摘要绑定用户并限制有效期，成功后不能重复绑定其他用户。
- 保留现有用户级素材隔离；任何客户端提交的 `GroupId` 都被忽略或拒绝。
- 前端不得通过自动打开弹窗启动核验。必须由用户点击按钮触发，避免浏览器弹窗拦截，也保留清晰的同意动作。

## 错误处理

- 未配置：503，页面引导联系管理员，不暴露具体密钥配置；素材库凭证或专用回调基地址任一缺失都视为未配置。
- 未登录：沿用 `PrivateRoute` 和 `UserAuth` 登录跳转。
- 待核验：返回稳定的 `pending` 状态，不使用 5xx。
- 链接过期：返回 `expired`，清除浏览器短期状态并允许新建会话。
- 核验失败：返回稳定错误码和安全消息，不直接展示可能包含内部信息的上游响应。
- 素材未授权：409，页面回到授权卡片。
- 素材不存在或不属于用户：404。
- BytePlus 暂时故障：502/503，保留当前页面状态并允许重试，不自动创建多个新会话。

## 国际化与可访问性

- 所有新增用户文字使用 `t('中文键')`。
- 同步 `zh`、`en`、`fr`、`ru`、`ja`、`vi` 翻译文件，并运行 i18n lint。
- 二维码同时提供文本链接和复制按钮，不能把二维码作为唯一入口。
- 状态颜色同时配有文字和图标；按钮、输入框、确认框和二维码说明可用键盘访问。

## 测试策略

### 后端

- 授权状态不泄露 `GroupId`。
- 会话创建只使用服务端回调地址，并保存令牌摘要而非原始令牌。
- 结果查询拒绝其他用户、未知摘要、过期和已消费会话。
- 成功核验保存用户绑定并完成会话；重复成功调用保持幂等。
- 素材 CRUD 继续强制当前用户组，覆盖跨用户 404。
- GORM 模型测试在 SQLite 上运行，并审查 MySQL/PostgreSQL 兼容性。
- 路由测试同时覆盖 `UserAuth` 控制台 API 和原有 `TokenAuth` API。

### 前端

- 授权状态机覆盖未配置、未授权、等待、成功、失败和过期。
- 桌面显示二维码，移动端显示直接进入 H5 的主操作。
- 页面刷新后从 `sessionStorage` 恢复轮询；成功或过期后清理令牌。
- 未勾选同意条款时不能创建授权会话。
- 素材 URL 校验、状态展示、复制引用、重命名和删除确认均有组件测试。
- 运行 `bun run i18n:lint` 和 `bun run build`。

### 上线与生产验收

1. 运行目标 Go 单元/路由测试、全量 Go 测试和前端构建。
2. 部署后验证匿名访问控制台 API 返回 401，普通登录会话可读取授权状态。
3. 使用管理员账号创建 H5 会话，确认桌面二维码与手机链接指向同一个短期授权会话。
4. 由管理员本人在有摄像头的手机上确认条款并完成真实活体核验；该步骤不能自动化。
5. 确认桌面轮询自动变为已授权，数据库只保存令牌摘要和用户绑定。
6. 使用管理员账号登记一条低风险测试素材，轮询到 `Active`，验证列表、重命名和归属隔离。
7. 使用管理员账号下的专用临时 API Token 发起最低成本允许规格的视频任务，引用 `asset://<asset_id>`；完成后删除临时 Token 和测试素材。
8. Canary 检查授权错误率、素材接口 5xx、前端控制台错误和视频任务最终结算。若出现权限或隔离回归，回滚应用版本；数据库新增会话表可保留为空，不影响旧路由。

## 完成标准

- 普通登录用户无需粘贴 API Token 即可进入真人素材库页面。
- 桌面无摄像头用户能够用手机完成 H5 活体核验，原设备自动得到授权结果。
- H5 过期、失败和用户取消都有可恢复路径。
- `GroupId`、原始 `BytedToken` 和服务端凭证不暴露给页面日志或其他用户。
- 用户只能管理自己绑定组中的素材。
- `Active` 素材可以复制为 `asset://` 并在 Seedance 生成任务中成功使用。
- 所有自动化测试、生产 smoke 和 Canary 通过；唯一人工步骤是本人在有摄像头设备上完成 BytePlus H5 核验。
