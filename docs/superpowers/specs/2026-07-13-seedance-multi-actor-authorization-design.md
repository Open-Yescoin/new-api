# Seedance 多演员真人授权与期限管理设计

日期：2026-07-13
状态：已确认，进入实施

## 背景与决策

现有 Seedance 真人素材库把一个 new-api 用户唯一绑定到一个 BytePlus
`LivenessFace` 素材组。该结构允许同一位真人登记多张图片和多个视频，但重新授权会覆盖
原绑定，因此不能满足短剧公司在一个账号下管理多位演员的需求。

本期将“真人”升级为用户账号下的一等资源“演员档案”。一个账号可以创建多个演员，
每个演员独立完成真人授权、拥有独立素材组、独立授权期限和独立素材列表。BytePlus
素材组仍严格遵守“一组一人”，不把不同演员的素材放入同一个上游组。

## 产品规则

### 演员与素材

- 一个账号可创建多个演员档案；演员显示名称在账号内必填，但不要求唯一。
- 每个演员在任一时刻最多绑定一个有效 BytePlus `GroupId`。
- 同一演员组可登记多张图片和多个视频；不同演员之间的素材不可见、不可改、不可引用。
- 现有单演员绑定在迁移时自动成为该用户的“默认演员”，不删除或移动上游素材。
- 旧控制台素材 API 在迁移期继续映射到默认演员；新页面和新 API 使用显式演员 ID。

### 授权期限

用户创建授权会话前必须选择以下一种期限：

| 展示选项 | 本地期限 | 说明 |
| --- | ---: | --- |
| 长期有效（演员可随时撤回） | 无固定本地到期日 | 不称为不可撤销的“永久”；仍受上游有效期约束 |
| 30 天授权 | 30 天 | 默认选项 |
| 60 天授权 | 60 天 | — |
| 半年授权 | 180 天 | — |
| 一年授权 | 365 天 | — |

- 不预选长期有效；默认选择 30 天。
- 期限和条款版本随授权会话形成不可修改的同意快照。
- 公司不能在演员未重新确认的情况下延长授权。
- 本地有效期从 BytePlus 真人授权成功时开始计算。
- 实际有效期取 Token123 本地期限与 BytePlus 上游有效期中较早者；若上游没有提供
  可验证的长期有效能力，页面不得承诺真正永久。
- 到期、演员撤回或上游判定失效均立即停止使用。

### 到期后的行为

到达 `authorization_expires_at` 的瞬间：

- 禁止新建素材和使用该演员的 `asset://` 引用生成视频。
- 允许列出、查看、重命名和删除旧素材，便于审计与清理。
- 不删除历史生成结果、账单、演员档案、素材记录或审计记录。
- 仅停用该演员，账号内其他有效演员不受影响。
- API 返回稳定错误码 `actor_authorization_expired`，HTTP 409。
- 页面显示“已过期”和重新授权入口，不再显示可复制引用的操作。
- 提前 7 天、3 天和 1 天显示站内提醒；提醒是辅助机制，不参与安全判定。

到期判定必须在每次受保护操作和视频提交时同步执行，不能只依赖后台定时任务。

## 用户流程

1. 企业用户进入“真人素材库”，看到演员列表和当前选中演员的素材。
2. 点击“新增演员”，填写显示名称并选择授权期限。
3. 服务端创建演员档案和绑定该演员的短期授权会话。
4. 桌面端显示指向 Token123 短期授权交接页的二维码，而不是直接展示 BytePlus H5 地址。
5. 演员在手机交接页看到公司/账号身份、演员名称、用途、期限、撤回方式和条款版本，主动勾选确认后才跳转 BytePlus H5 活体核验；移动端可直接进入同一交接页。
6. 原设备轮询结果。成功后服务端把返回的 `GroupId` 绑定到该演员，并计算有效期。
7. 企业在该演员下登记多个图片或视频素材，复制 `asset://` 引用进行生成。
8. 到期前提示重新授权；到期或撤回后立即停用，重新授权成功后恢复。

重新授权不假设 BytePlus 能恢复旧素材组。若上游返回新 `GroupId`，系统重新绑定该演员；
旧素材保持只读/可删除，且不得自动宣称已经迁移。只有上游 API 明确证明可安全复用时，
才能恢复原组素材使用。

## 后端结构

### 数据模型

新增 `VolcAssetActor`：

- `Id`、`UserId`、`DisplayName`
- `GroupId`（只在服务端使用，API 永不返回）
- `Status`：`Pending`、`Active`、`Expired`、`Revoked`
- `AuthorizationDurationDays`：30、60、180、365；长期有效为 `NULL`
- `AuthorizedAt`、`AuthorizationExpiresAt`（长期有效为 `NULL`）
- `ConsentVersion`、`CreatedAt`、`UpdatedAt`
- `(UserId, Id)` 和 `(UserId, Status)` 索引；不再对 `UserId` 做唯一约束

扩展 `VolcAssetAuthorizationSession`：

- 增加 `ActorId`，会话查询和消费必须同时匹配 `UserId + ActorId + TokenHash`。
- 增加 `DurationDays`（可空）和 `ConsentVersion`，保存演员确认时的快照。
- 增加 `InvitationTokenHash`、`ConsentAcceptedAt` 和 `RevocationTokenHash`。数据库只保存
  SHA-256 摘要，不保存原始交接或撤回令牌。
- 创建新会话只使同一演员的旧 `Pending` 会话过期，不影响同账号其他演员。

新增 append-only `VolcAssetAuthorizationEvent`：

- 保存演员、用户、事件类型、期限快照、发生时间和安全元数据。
- 事件包含创建、授权成功、重新授权、过期判定和撤回。
- 不保存原始 H5 Token、人脸图片 URL、AK/SK 或完整 `GroupId`。

所有字段使用 GORM 通用类型和迁移，兼容 SQLite、MySQL 5.7.8+、PostgreSQL 9.6+。

### API

在 `UserAuth` 下新增：

| 方法与路径 | 作用 |
| --- | --- |
| `GET /api/seedance/actors` | 列出当前账号演员与安全授权状态 |
| `POST /api/seedance/actors` | 新建演员档案 |
| `PATCH /api/seedance/actors/:actor_id` | 修改显示名称 |
| `DELETE /api/seedance/actors/:actor_id` | 删除无有效授权或已清空的演员档案 |
| `GET /api/seedance/actors/:actor_id/authorization` | 读取授权状态与到期时间 |
| `POST /api/seedance/actors/:actor_id/authorization/session` | 创建该演员的 H5 会话 |
| `POST /api/seedance/actors/:actor_id/authorization/result` | 查询并消费该演员会话 |
| `POST /api/seedance/actors/:actor_id/authorization/revoke` | 当前账号立即撤回该演员授权 |
| `GET /api/seedance/actors/:actor_id/assets` | 列出该演员素材 |
| `POST /api/seedance/actors/:actor_id/assets` | 新建该演员素材 |
| `GET/PATCH/DELETE /api/seedance/actors/:actor_id/assets/:id` | 管理该演员素材 |

客户端永远不能提交 `GroupId`。所有演员和素材操作先校验演员属于当前用户，再由服务端解析
演员绑定组。跨账号访问统一返回 404，避免泄漏资源存在性。

另提供不依赖登录 Cookie 的短期公开接口，且只接受请求体中的高熵一次性令牌：

| 方法与路径 | 作用 |
| --- | --- |
| `POST /api/seedance/public/authorization/details` | 用交接令牌读取安全的演员、用途和期限摘要 |
| `POST /api/seedance/public/authorization/consent` | 演员确认条款并激活进入 H5 的资格 |
| `POST /api/seedance/public/authorization/revoke` | 演员使用保存的撤回令牌立即撤回授权 |

二维码 URL 使用 `https://www.token123.co/seedance/authorization/consent#...` 的 fragment
携带交接令牌和预先创建的 H5 地址。fragment 不会发送到 Web 服务器；交接页只在服务端确认
同意成功后才跳转 H5。原设备继续在 `sessionStorage` 保存上游短期令牌并轮询，因此服务端
数据库仍不需要保存原始 `BytedToken` 或完整 H5 地址。

同意成功时手机端获得一枚高熵撤回令牌并暂存于本域 `sessionStorage`。H5 回调返回 Token123
后，页面向演员展示可保存的撤回链接；数据库只保存摘要。公开撤回接口命中后立即把演员
标为 `Revoked` 并阻断平台调用。若上游不允许立即删除仍有效的真人组，平台保留删除请求
审计并按上游支持流程处理，但不能因此延迟本地停用。

### 生成请求拦截

`asset://<asset_id>` 仍保持对外兼容。提交 Seedance 任务前，服务端通过 BytePlus 素材归属
或本地安全映射确定对应演员，并检查其授权是否 `Active` 且未到期。未授权、已撤回或已到期
时在调用上游前返回 409，不能只在素材管理页面隐藏按钮。

若现有上游接口无法从裸 `asset_id` 稳定反查演员归属，则本期在素材创建成功后保存
`VolcAssetActorAsset(ActorId, AssetId)` 映射，并在列表同步时补齐；映射只作归属索引，
最终仍以当前用户、演员组和上游结果共同校验。

## 前端结构

- 页面左侧/顶部为演员选择器，展示名称、授权状态和到期时间。
- 右侧为当前演员的授权卡片与素材列表。
- “新增演员”弹窗包含名称和授权期限；默认 30 天。
- 长期选项显示为“长期有效（演员可随时撤回）”。
- 状态至少包含待授权、授权中、有效、即将到期、已过期和已撤回。
- 即将到期在 7/3/1 天显示提示；已过期隐藏复制引用和新建素材操作，但保留查看、重命名和删除。
- 二维码页面明确展示所授权演员和期限，手机完成后桌面继续自动轮询刷新。
- 公共授权交接页在同意前不进入 BytePlus；回调页展示“已完成，可返回原设备”和可保存的
  撤回入口，不要求演员登录企业账号。
- 所有新增文本使用 `t('中文键')` 并同步项目现有语言文件。

## 安全与合规

- 每位演员必须独立主动确认，不能由企业账号批量代替确认，也不能复用另一位演员的核验。
- “长期有效”始终可撤回；撤回和到期使用同一实时拦截路径。
- 授权同意快照至少包含账号、演员、用途、期限、条款版本和时间。
- `GroupId`、原始 `BytedToken`、AK/SK 和素材源 URL 不进入审计事件或前端日志。
- 任何写操作必须验证 `UserId + ActorId`；任何素材操作还需验证对应组或映射。
- 服务端时间为唯一到期依据，前端倒计时只用于展示。

## 错误语义

- 演员不存在或不属于用户：404 `actor_not_found`
- 演员待授权：409 `actor_authorization_required`
- 演员已到期：409 `actor_authorization_expired`
- 演员已撤回：409 `actor_authorization_revoked`
- 会话已过期：410 `authorization_session_expired`
- 上游真人授权失效但本地尚未到期：同步标记演员失效并返回 409
- BytePlus 暂时故障：502/503，不篡改已有有效授权状态

## 迁移与兼容

1. GORM 创建演员、事件以及可选素材映射表，并为授权会话增加演员和同意快照字段。
2. 对每条现有 `VolcAssetUserGroup` 建立一个“默认演员”，复制原 `GroupId` 和更新时间。
3. 迁移无法证明原授权期限时，不伪造永久授权；标记为需要重新确认的兼容状态，允许查看和删除，禁止新生成。
4. 旧 API 暂时解析默认演员并返回现有响应格式；新页面只调用演员 API。
5. 迁移和回填必须幂等，应用重复启动不能创建重复默认演员。

## 测试与验收

### 自动化

- 同账号可创建多演员，名称可重复但 ID 不同。
- 演员 A 重新授权不会覆盖演员 B 的绑定或待处理会话。
- 每位演员可以登记多个素材；跨演员和跨用户访问返回 404。
- 30、60、180、365 天和长期有效的到期时间计算正确。
- 到期边界前一秒允许、到期瞬间拒绝；服务器时区不影响 Unix 时间比较。
- 到期演员禁止创建和生成，但允许列表、重命名和删除；其他演员继续可用。
- 撤回与到期使用相同实时保护；前端不能绕过后端。
- H5 会话的重复轮询和成功回调保持幂等。
- 旧绑定迁移为唯一默认演员且重复迁移无副作用。
- API 响应和日志不包含 `GroupId`、原始 Token 或服务端凭证。
- Go 目标测试、全量测试、前端状态测试、i18n lint 和 Bun 构建通过。

### 生产验收

- 使用管理员账号创建至少两个演员档案，分别生成授权会话，确认互不覆盖。
- 由真人在手机上完成其中一名演员的 H5 授权，确认电脑自动刷新到正确演员。
- 登记两个低风险素材并验证列表、重命名、删除和归属隔离。
- 使用管理员账号的临时 Token 进行最低成本 `asset://` 视频调用，并核对计费仍为成本加价 20%。
- 通过可控测试数据验证过期瞬间返回 409，且另一名有效演员仍可使用。
- 清理临时 Token 和测试素材；不得修改普通测试用户余额。

真实演员的 H5 活体核验无法也不应自动化；除该真人动作外，其余发布、测试和回归均可自动执行。

## 完成标准

- 一个账号可安全管理多个演员，每位演员拥有独立授权、期限、素材组和素材列表。
- 五种期限选择完整可用，默认 30 天，长期授权可随时撤回。
- 到期或撤回在所有生成入口同步立即拦截，不依赖页面或定时任务。
- 旧单演员数据可安全迁移且不被误标为永久授权。
- 自动化测试、前端构建和上线前回归通过；生产真人授权步骤明确保留给本人。
